## Зачем он нужен

Коммерческий VPN предлагает доверить компании ровно тот трафик, который вы пытаетесь укрыть.
Свой сервер эту компанию убирает, но обычно взамен требует вечера с SSH, Docker и конфигами.

AbstractumVPN проводит этот вечер за вас и после этого не мешается. Сервер ваш. Ключи ваши.
Наружу ничего не уходит.

## Как это работает

То, чем он отличается от прочих клиентов: **он разворачивает сервер сам.**

```
   вы                      ваш сервер                     интернет
   │                          │                              │
   │  1. заходит по SSH,      │                              │
   ├─────────────────────────►│                              │
   │     ставит Docker        │                              │
   │                          │                              │
   │  2. подключается         │                              │
   ├═════════════════════════►│─────────────────────────────►│
   │     шифрованный туннель  │                              │
```

Вводите адрес, логин и пароль или ключ. Клиент заходит по SSH, ставит Docker, если его нет,
собирает контейнер под выбранный протокол и подключается. Убрать всё обратно - одна кнопка.

## Что нужно от сервера

Любая Linux-машина, которой вы владеете, доступная по SSH. Руками настраивать нечего.

| | |
|---|---|
| **Дистрибутив** | Любой с `apt-get`, `dnf`, `yum`, `zypper` или `pacman` и systemd. Debian, Ubuntu, Fedora, CentOS, openSUSE, Arch подходят |
| **Доступ** | SSH под `root` или под пользователем в группе `sudo` / `wheel` |
| **Docker** | Ставится сам, если его нет. Готовить ничего не надо |
| **Порты** | Открываются сами в брандмауэре хоста. По умолчанию: OpenVPN `1194`, WireGuard `51820`, AmneziaWG `55424`, XRay и Cloak `443`, IKEv2 `500` и `4500` UDP |

Перед установкой клиент смотрит на файл блокировки пакетного менеджера. Если на сервере уже
что-то ставится, он честно откажется, а не полезет вторым процессом.

## Протоколы

| | Когда брать |
|---|---|
| **AmneziaWG** | По умолчанию. Скорость WireGuard плюс обфускация, чтобы трафик не выглядел как WireGuard |
| **WireGuard** | Быстро и просто, если трафик никто не разглядывает |
| **OpenVPN** | Зрелый и всем понятный. Медленнее |
| **OpenVPN через Cloak** | Соединение становится похоже на обычный HTTPS |
| **OpenVPN через Shadowsocks** | Ещё один слой маскировки, если Cloak заблокирован |
| **XRay** | Обход глубокого анализа пакетов |
| **IKEv2** | Встроен в Windows, драйверов не требует |

`AmneziaWG` и `AmneziaDNS` намеренно сохранили свои имена: это компоненты, которые вы ставите
на свой сервер, а не наш бренд. Переименуй мы их - вы перестали бы узнавать в настройках то,
что реально развернули.

## Что ещё он умеет ставить

**По умолчанию не ставится ничего из этого.** Выбрали протокол - получили протокол, и только
его. Ниже то, что при желании можно добавить потом, по одной штуке: откройте сервер в
настройках, вкладка **Сервисы**, выберите нужное - клиент поставит его по тому же SSH.
Удаляется той же кнопкой.

| | |
|---|---|
| **AmneziaDNS** | Резолвер `unbound`, доступный только внутри туннеля, с пересылкой по DNS-over-TLS. Запросы перестают уходить провайдеру |
| **SFTP-хранилище** | Личный файловый доступ на сервере |
| **SOCKS5-прокси** | Для приложений, которые умеют SOCKS, но не VPN |
| **MTProxy** | Прокси Telegram на вашем сервере - чтобы раздать доступ другим людям |
| **Сайт в Tor** | Публикует ваш сайт как onion-сервис |

Инструкции, как поставить это руками, нет, потому что руками ставить нечего.

## Установка

Возьмите сборку в [релизах](https://github.com/FFriends/AbstractumVPN/releases/latest).

| | |
|---|---|
| **Windows** | `AbstractumVPN_*_windows_x64.exe` |
| **Linux** | `AbstractumVPN_*_linux_x64.run` |

Пока проект молодой, релизы выкладываются с пометкой pre-release - смотреть стоит страницу
релизов целиком, а не искать «последний стабильный».

Сборки пока без цифровой подписи, поэтому Windows SmartScreen предупредит о неизвестном
издателе. macOS, Android и iOS не собираются: код их поддерживает, а сертификатов подписи и
аккаунтов в магазинах нет.

Установленный клиент сам смотрит релизы этого репозитория и предлагает обновиться. Запрос
уходит без тела и не несёт ничего, что опознаёт вашу установку.

## Сборка

**Локальной сборки нет.** Всё собирается в GitHub Actions, и это решение, а не упущение:
Qt 6.10 плюс девятнадцать зависимостей Conan из исходников - не тот тулчейн, который стоит
воспроизводить на каждой машине.

Цикл: правка, пуш, смотреть [Actions](https://github.com/FFriends/AbstractumVPN/actions).
Ежедневная задача в 03:00 UTC собирает всё новое; еженедельная, по воскресеньям в 09:00 UTC,
выкладывает релиз - и только если с прошлого раза появились коммиты.

Тулчейн можно поднять, если нужен отладчик: CMake 3.25+, Conan 2.x, Qt 6.10+ **с модулем Qt
Remote Objects** - в стандартную установку Qt он не входит, и без него привилегированная
служба не соберётся вовсе. Дальше `deploy/build.sh` или `deploy\build.bat`. Ничего в проекте
на этом не завязано.

## Безопасность

Об уязвимостях сообщайте через
[GitHub Security Advisories](https://github.com/FFriends/AbstractumVPN/security/advisories/new).
Обсуждение остаётся приватным, пока не выйдет исправление, и этот канал работает, даже когда
трекер задач закрыт. Что считаем своим, а что нет, и в какие сроки отвечаем -
[SECURITY.md](SECURITY.md).

Клиент состоит из двух частей: обычного приложения и службы с системными правами, которой
принадлежат маршруты, интерфейс туннеля и kill switch. Эта граница и есть то, что стоит
рассматривать пристально, - работа шла именно там:

- привилегированные каналы обслуживают клиент, установленный рядом со службой, и отказывают
  всем остальным; это проверяется на каждом соединении, а не предполагается;
- аргументы, уходящие в процессы с системными правами, проходят через белый список для
  каждого процесса, а незнакомая опция отменяет весь запуск, а не отбрасывается тихо.

Одно, что стоит знать заранее, потому что не исправлено:

- **На Linux список серверов не шифруется.** В апстриме это отключили, потому что keychain там
  работает ненадёжно, и мы это пока не заменили. Адреса серверов и ключи лежат в `QSettings`
  открытым текстом.

## Лицензия и происхождение

GPL-3.0, см. [LICENSE](LICENSE) и [NOTICE](NOTICE).

AbstractumVPN основан на
[amnezia-vpn/amnezia-client](https://github.com/amnezia-vpn/amnezia-client), влит до среза
`0d116bfc`. Большая часть кода написана ими, и лицензия унаследована, а не выбрана: GPLv3
этого требует.

Проект независимый, с Amnezia не связан и ими не поддерживается. **О проблемах с
AbstractumVPN сообщайте сюда, а не им.** Чем отличается: нет подписок, нет платного хостинга,
нет рекламы, нет аккаунта и нет обращений к чужим серверам - проверка обновлений идёт в этот
репозиторий, всё остальное на машину, которую вы подняли сами.

Сторонние компоненты и их лицензии перечислены в
